# My agent: FitTrack AI
One-liner: A conversational agent that helps gym-goers achieve weight loss goals with a catalog of gym workout routines, workout tracking, and calorie-conscious nutrition plans.

Tool coverage:
- Memory: User profile (current weight, target weight, height, gender, activity level), workout history, and dietary preferences.
- Tools: Log daily weight and completed workouts, search gym routines by muscle group and equipment, calculate target caloric deficit and look up meal options.
- Catalog/UI: Catalog of gym workout routines (exercises, sets, reps, muscle focus) and low-calorie recipe cards/tables.
- Image gen: Motivational progress milestone visuals and healthy balanced meal plating concepts.
- Sandbox: Code sandbox for precise calculation of TDEE (Total Daily Energy Expenditure), custom caloric deficit, and projected weight loss trajectories.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for caloric deficit calculations and progress projections, Cloud Trace for telemetry.
